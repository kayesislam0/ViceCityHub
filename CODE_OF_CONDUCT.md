# Code of conduct

Vice City Hub is a small fan project. Keep it a place people enjoy helping out.

**Expected:** be kind and patient, assume good intent, criticise code rather than people, and welcome first-time
contributors.

**Not accepted:** harassment, insults, slurs, sexual content, threats, doxxing, spam, and asking anyone for money or
crypto. The project will never ask you to send crypto in an issue, a comment or a message.

**What happens:** the maintainer may edit or remove comments, close issues or pull requests, and block accounts that
break these rules.

**Reporting:** to report something privately, use GitHub's "Report content" option on the comment or account, or
contact the maintainer through their GitHub profile.
